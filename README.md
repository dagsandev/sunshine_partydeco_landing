# Sunshine Party Deco

Landing page for **Sunshine Party Deco**, a small business from Buenos Aires that designs handmade decorations and creative stationery for children's parties: 3D numbers and letters, cake toppers, centerpieces, candy bars, stickers and more.

**Live site:** [sunshine-partydeco.vercel.app](https://sunshine-partydeco.vercel.app)

Built with [Astro](https://astro.build) and [Tailwind CSS](https://tailwindcss.com), hosted on Vercel.
